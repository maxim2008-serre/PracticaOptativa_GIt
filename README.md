# Práctica OPTATIVA GIT

## Descripción
Este proyecto corresponde a una práctica sobre el uso
del sistema de control de versiones Git y GitHub.

## Objetivos
- Crear repositorios locales.
- Crear y gestionar ramas.
- Realizar commits.
- Conectar Git con GitHub.
- Subir proyectos a repositorios remotos.
- Clonar repositorios.
